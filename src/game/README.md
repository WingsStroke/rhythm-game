# src/game

Contains the prototype level definition. This directory is the only place where concrete level content is authored in code; all other modules are agnostic to the specific level being played.

---

## Module Overview

### createPrototypeLevel.ts

Generates and exports a `LevelData` object representing the prototype level.

Exports:

| Export | Type | Description |
|---|---|---|
| `createPrototypeLevel(songUrl?)` | Function | Returns a `LevelData` object. If `songUrl` is provided, the level references an external audio file. Otherwise, the engine falls back to the procedural synthesizer. |
| `SONG_URL` | string | The path the application checks for an external audio file (`/song.mp3`). |

Pad layout (current prototype):

| Pad ID | Label | Key | Role |
|---|---|---|---|
| `kick` | Kick | A | kick |
| `snare` | Snare | S | snare |
| `lead` | Lead | D | lead |
| `alt` | Alt Lead | F | lead |

Timing windows (seconds):

| Window | Value |
|---|---|
| Perfect | 0.050 |
| Good | 0.120 |
| Miss | 0.250 |

The initial event sequence is generated by `BeatmapGenerator` from `src/engine/beatmap/`. Events are ordered chronologically by `targetTime`.

### GameScreen.tsx

Independent full-screen gameplay view (Standalone Player). Projets PixiJS rendering into a fixed 1920×1080 logical resolution viewport with automatic letterboxing/pillarboxing. Manages the lifecycle of `Game.ts`, handles Escape key pause, and coordinates the HUD and modals.

### components/GameHUD.tsx

Real-time in-game HUD. Displays the top progress bar with elapsed and remaining time, combo streak, dynamic animated multiplier (1x, 2x, 4x, 8x), live accuracy percentage (`Accuracy %`), and hit breakdown counters.

### components/PauseModal.tsx

Modal displayed on pressing Escape or pause button. Freezes `AudioTransport` and the PixiJS ticker, providing options to Resume, Restart track, or Exit.

### components/ResultsModal.tsx

Performance summary modal deployed automatically when the song concludes. Displays final score, SS/S/A/B/C/D rank badge, accuracy, max combo, and judgement breakdown.

---

## Adding a New Level

To add a new level, create a new file in this directory following the same pattern as `createPrototypeLevel.ts` or import a JSON beatmap from the start screen or editor. Return or load a valid `LevelData` object. Wire it into `App.tsx` or load dynamically. No engine code needs to be modified.
